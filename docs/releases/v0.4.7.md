# v0.4.7 — 服务器拖拽排序与独立连接器

服务器卡片和左侧已连接列表都可以拖拽排序，两处顺序同步保存；Jellyfin 与 Emby 的协议实现拆分为独立连接器，便于后续适配其他媒体服务器后端。

## 服务器排序

- 在服务器页面的卡片区，或左侧「已连接的服务器」列表中，按住服务器并拖动即可调整顺序，也支持跨区域拖放。
- 拖动时，带图标、名称和协议的卡片或服务器行会跟随鼠标，原位置保留虚线占位，目标位置显示插入线。
- 松开鼠标后，两处顺序同步保存，重新启动应用仍会保留；按 Esc、拖到无效区域或失焦可取消本次排序。
- 服务器较多时，拖到滚动区域边缘会自动滚动。也可以聚焦服务器后，使用 Alt+↑/↓ 调整顺序。
- 保留普通点击打开、右键编辑和卡片编辑/删除操作。排序不改变登录账号、令牌、设备身份或当前选中的服务器。

## 连接器结构

- Jellyfin 和 Emby 拆分为独立连接器，各自维护产品识别、鉴权方式、API 别名、筛选接口与播放协商差异。
- 页面和状态层使用统一媒体 API 契约与连接器工厂。新增后端只需实现连接器并加入注册表，服务器类型、客户端标识设置及相应能力会自动接入。
- 保留现有连接数据和旧构造调用方式，以及手动协议选择、代理前缀、跨域兼容、令牌隔离和设备身份规则。
- 扩展流程已写入 README，并增加独立第三连接器的本地回归测试。本版实际支持的服务器后端仍为 Jellyfin 和 Emby。

## 下载与使用

- `MyJellyfinClient_0.4.7_x64-setup.exe`：Windows x64 安装版。
- `MyJellyfinClient_0.4.7_x64-portable.exe`：单 EXE 便携版，需要系统已安装 WebView2 Runtime。账号与设置保存在 EXE 旁的 `MyJellyfinClient-data` 文件夹；更新时请保留这个文件夹。
- `SHA256SUMS.txt`：安装版与便携版的 SHA-256 校验值。

本版无需清空账号、设置或开发数据。更新安装版可使用新安装包覆盖安装。
